# tidewatch

Fortran 77 tide solver with a Python 3 harness; every test needs the mainframe emulator on `:3270` (`make emu` starts it).

## Commands

- Test: `make test MOD=<module>` # one module under `src/`
- Single test: `python3 -m pytest harness/tests -k <name>`
- Full check: `make lint && make test && make tables-check`
- Lint: `make lint` (fprettify plus ruff; no fix target)
- Build/run: `make solver && ./bin/solver harbour/falmouth.dat`
- Generate: `make tables` # after editing `harbour/*.dat`; writes `src/tables/*.f`
- Prerequisites: `EMU_HOST` (default `127.0.0.1:3270`); the emulator from `make emu`; `gfortran` 11 or newer

## Layout

| Path | What lives there |
|---|---|
| `src/tables/` | Generated by `make tables`; never edit by hand. |
| `harness/vendor/pyemu/` | Owned by the emulator project; change it there. |

## Conventions

- Tide heights are `INTEGER*4` millimetres end to end; a `REAL` height is a bug.
- Harbour ids are the four-letter codes in `harbour/index.txt`; the solver never sees a name.

## Landmines

- `make tables` reads `harbour/*.dat` in directory order; a renamed file shifts every table id. Run `make tables-check` after any rename.
- The solver writes `moon.cache` next to its input and reuses it silently; delete it after editing any `.dat`.

## Boundaries

- Always: `make lint && make test && make tables-check` before handoff.
- Ask first: `make publish`; any change under `harness/vendor/`.
- Never: edit `src/tables/`; commit `moon.cache`; point `EMU_HOST` at the shore station.
